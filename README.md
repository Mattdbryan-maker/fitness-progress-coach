## Current Features

The Fitness Progress Coach currently allows users to:

- Load workout records from a CSV file.
- Add new exercises.
- Record a different number of reps for every set.
- Save workouts permanently.
- View workout history.
- Group exercises completed on the same date.
- Add multiple exercises in one workout.
- Handle invalid weight, set and rep inputs.
- Navigate the application using an interactive menu.

## Current Development Stage

The project is currently at Version 0.4.

The next planned feature is chronological workout sorting using Python's `datetime` module.
